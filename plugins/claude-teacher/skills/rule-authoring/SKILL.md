# Authoring a rule

**No rule-authoring guidelines exist yet.** This skill is a stub, and saying so is its whole job:
without it, doctrine gets invented on the spot or borrowed from skill authoring, and neither is
right.

So, until it is written:

- **Do not carry skill doctrine over.** A rule is not a skill. It is not chosen, it has no archetype,
  and its content is not shaped by the same tests.
- **Take the form from the project's own rule files**, read before writing. They are the only
  authority on this that currently exists.
- **State what has no precedent as an open question**, rather than settling it silently.
